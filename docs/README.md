# Documentação do projeto
Os arquivos finais ficam no Google Drive (pasta 06_DOCUMENTACAO). Aqui no repositório ficam as cópias versionadas:

- `requisitos/` – RF, RNF e regras de negócio (ex.: `REQ_RF01_Autenticacao_Eleitor.pdf`)
- `banco/` – modelo conceitual, lógico, DER e dicionário (ex.: `DER_Simulador_Urna_v01.png`)
- `arquitetura/` – diagrama MVC e fluxo de rotas
- `testes/` – plano e casos de teste (ex.: `Plano_Testes_v01.xlsx`)
- `evidencias/` – prints (ex.: `Evidencia_CT05_20261019.png`)
